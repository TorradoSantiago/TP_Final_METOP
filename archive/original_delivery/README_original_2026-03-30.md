# TP_Final_METOP

Repositorio base para un trabajo final. El repo original no tenia contenido visible; en esta iteracion se deja una estructura conceptual minima para que el proyecto pueda empezar con mejor orden y presencia.

## Estructura sugerida

- `data/`: insumos crudos y procesados.
- `scripts/`: limpieza, analisis y funciones auxiliares.
- `notebooks/`: exploracion o borradores.
- `outputs/`: tablas, figuras y entregables.
- `README.md`: objetivo, metodologia y resultados.
