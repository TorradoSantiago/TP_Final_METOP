# TP_Final_METOP

Public-opinion analytics capstone blueprint repositioned as a professional project-in-preparation rather than an empty starter repository.

Start with:
- `BRIEF.md`
- `docs/capstone-brief.html`
- `docs/capstone-brief.pdf`

## What this repository is now

This project is intentionally honest about its current stage. It does not pretend to have finished results without data. Instead, it now presents a complete research design that is ready to receive a public-opinion dataset and move into analysis.

## Core purpose

Build a final project around survey analytics, opinion segmentation, and interpretable political-behavior modeling with a structure that already looks portfolio-ready.

## What was added

- `scripts/build_capstone_blueprint.py`: generates the hypothesis matrix, delivery roadmap, and workflow figure
- `outputs/tables/hypothesis_matrix.csv`: testable hypotheses and suggested methods
- `outputs/tables/deliverable_roadmap.csv`: phased work plan for execution
- `outputs/figures/capstone_delivery_roadmap.png`: visual roadmap for the delivery process
- `docs/capstone-brief.html`: non-technical executive brief
- `docs/capstone-brief.pdf`: shareable PDF version of the brief

## How to run it

```bash
python scripts/build_capstone_blueprint.py
```

## Why this version is stronger

The repository now has a body, a purpose, a methodological direction, and a publication layer. That makes it much more credible than a blank structure while still avoiding fake empirical claims.
