## Why the project is stronger now

The repository now shows the part that many capstones skip: the research architecture that sits between a vague topic and a finished empirical case.

- It defines six hypotheses instead of a loose intention.
- It specifies theoretical constructs and their observable proxies.
- It maps each stage to a concrete methodological family.
- It includes a validity matrix so the project does not overclaim.
- It lays out a realistic execution and packaging sequence.

## Theoretical direction

The capstone is designed around a set of connected political-behavior mechanisms:

1. Economic expectations and retrospective voting.
2. Institutional trust and legitimacy.
3. Issue salience and voter segmentation.
4. Sociodemographic moderation of political behavior.
5. Candidate evaluation through valence and ideological proximity.
6. Media environments as a force shaping expectations and trust.

## Methodological direction

The blueprint is now much more technical than a generic outline. It explicitly plans for:

- scale reliability and dimensionality checks,
- weighted descriptive analysis,
- non-parametric distribution tests,
- logit and multinomial models,
- segmentation methods,
- robustness and sensitivity checks.

## Conclusion

The repository no longer looks unfinished. It now looks prepared. That is a much stronger signal for a portfolio or academic context because it demonstrates the ability to define a serious analytical project before the final dataset is even loaded.
